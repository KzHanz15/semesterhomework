关于作品

作品简介

「星空天文馆」是一个面向天文爱好者的科普展示型 Web 作品，将八大行星的科学数据以文字、图表与三维场景三种形式呈现，帮助用户直观理解太阳系的构成。

功能模块

  • 行星档案：基于 JSON 数据渲染行星卡片，支持搜索、类型筛选、排序、收藏与详情弹窗。
  • 数据可视化：使用 ECharts 绘制柱状图、饼图、雷达图。
  • 三维太阳系：使用 Three.js 构建可交互的三维场景，支持旋转、缩放与点击查看。
  • 错误处理：覆盖网络失败、数据为空、非法输入三种场景。

技术栈

  • HTML5 语义化标签 + CSS3（Flex/Grid 布局、媒体查询响应式）
  • 原生 JavaScript（ES5 风格、Fetch API、localStorage）
  • ECharts 5.5（数据可视化）
  • Three.js r147 + OrbitControls（三维场景）
  • JSON（数据组织与加载）

如何运行

  • 由于页面通过 Fetch 加载本地 JSON，请使用本地 HTTP 服务器（而非直接双击打开）。
  • 在项目根目录运行：npx serve . 或任意静态服务器，然后访问 http://localhost:3000。
